# AquaOasis-Web Main Site

This is the future full AquaOasis-Web marketing site, kept separate from the current maintenance/front page.

## Positioning

AquaOasis-Web helps physical businesses, startups, and creators enter the digital age through a clear product ladder:

1. Getting You Online - Google Business Profile, photos, copy, reviews, and review landing page.
2. Website Build - conversion-ready websites from £899, scoped around what the business actually needs.
3. Creator Setup - social account foundations, profile setup, and presence cleanup for creators.
4. Growth - SEO, social media, ads, and traffic support after the foundation is built.

## Local Dev

From this folder:

```bash
npm run dev -- --port 3003
```

In this Codex workspace, npm may not be on PATH. Running the app through the parent runtime/node_modules also works.
